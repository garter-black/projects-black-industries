Every net present value on this page is a TARGETED ESTIMATE. Not an actual, not a projection, not a forecast. It is the number a project is being aimed at, computed live in your browser from inputs that are visible and checkable. All figures: targeted estimate

The formula

NPV = -outlay + Σ CFₜ / (1 + r)ₜ

Discount factors are computed at render, never stored. Open the working on any project and check the arithmetic by eye.

The order

Sorted by targeted NPV, smallest to largest. Not by group, not by number. The card numbers are inherited and deliberately non-sequential: there is no fifteen.

The honesty

One project carries illustrative round inputs, marked in the source as an example to be replaced. The rest are seeded empty on purpose. Invented cash flows would make this document worthless.
